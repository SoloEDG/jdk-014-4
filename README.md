# PANEL

安装：`npm install`

本地启动：`npm run dev`

生产构建：`npm run typecheck && npm run build`

单元测试：`npm test`

Docker 启动：`docker compose up --build`，访问 http://localhost:3014。

## 讲解式阅读会话

把一次讲解的翻页、分镜选择、缩放停留与声音切换逐次录成可回放的阅读会话。

- **逐次记录意图**：保存的是带时间戳的操作事件（分镜身份引用 + 可见位置），不是画面快照，因此仍保留可搜索的分镜关系。
- **录制控制**：可暂停、继续，暂停期间可自由重看与临时关闭声音；可随时“重看”当前镜头（追加记录而不回退时间线）。
- **忠实回放**：按时间先后还原可见位置、对白显隐与声音开关。
- **拖动不串音**：回放调度采用代次（generation）机制，拖动时间点会使拖动前仍在等待的声音回调全部作废，迟到的异步音频启动也会被停掉。
- **版本引用与重新关联**：每个会话记录录制时的作品版本指纹；作品修改后按稳定 id 重新关联，id 失效时用录制序号兜底，彻底失联的片段明确标注为“无法匹配”并在回放时跳过，绝不静默改指别的画面。
- **删除保护**：删除被会话引用的章节前，弹窗列出受影响的会话与失联镜头数，确认后才执行。

会话存储于浏览器 `localStorage`（键 `panel-jdk014-sessions-v1`），与阅读进度分开保存。
